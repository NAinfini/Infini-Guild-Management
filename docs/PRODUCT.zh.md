# 产品说明

[文档首页](../README.md) · [English version](./PRODUCT.md)

## 产品是什么

Infini Guild Management 是一个适用于桌面和手机的响应式双语公会管理应用。

## 服务对象

- **公会成员**可以查找当前公会信息、管理个人资料和缺席记录、参加活动、投票或参与抽奖、查看公会战计划与历史，并使用共享百科、媒体、仓储及获准工具。
- **版主和管理员**可以发布内容、协调活动与公会战、维护成员和目录、管理仓储、查看运维记录，以及管理角色、权限和站点政策。
- **访客**可以浏览总览、活动、成员、公告、公会战、图库、百科、设置和工具。个人资料、仓储、管理后台及其他高权限修改需要登录，并由服务端校验权限。

## 产品目的

本应用为公会提供一个统一的运维入口，避免权威信息散落在表格、聊天置顶、媒体目录和临时工具中。成员无需技术帮助也应能找到信息并完成常用任务；工作人员应能依靠清晰权限和有效审计记录管理公会。

## 当前支持的能力

- 使用总览摘要和命令搜索；浏览成员、资料、职业、徽章、可用时间、缺席、媒体及成员自行控制的资料音频。
- 使用邀请码注册、管理账号设置和 Cookie 会话、设置资料称号样式，并在全部支持的屏幕尺寸上使用英文或中文。
- 参加具有固定行为的活动、周期模板、配额、报名、参与者管理、投票、抽奖和自动归档。
- 阅读定时发布的富文本公告、百科分类/文章/修订、图库图片和外部视频，以及经过审核的内容。
- 规划进行中的公会战、移动队伍与候选池、结算、查看历史和成员数据并导出分析。
- 使用需要登录的仓库结构、分类、物品、数量、图片和出入库历史。
- 使用骰子工具，并在获得授权时管理成员、邀请、角色、权限、站点配置、职业、职业标签、徽章和审计/错误/状态数据。
- 在计划中的数据或 Blob 存储维护期间，操作者可让任一运行时返回不依赖应用的双语维护响应，而不在应用内暴露维护开关。
- 通过登录态 WebSocket 接收实时更新提示；Cloudflare 使用 Durable Object，VPS 使用进程内 hub。

## 产品边界

- 运行时功能开关仅限 `announcements`、`events`、`guildWar`、`gallery`、`wiki`、`tools` 和 `storage`。
- 站点配置拥有品牌、上述功能开关，以及媒体、仓储和缺席政策。游戏规则仍是源码契约。
- 活动类型固定为 `weekly_mission`、`guild_war`、`social`、`poll`、`raffle` 和 `other`。
- 公会战结果固定为 `win`、`loss` 和 `draw`。KDA 为 `(kills + assists) / max(deaths, 1)`，展示前不提前舍入。每个数据定义只有一个 `name`，不支持本地化 `labels` 或可配置 `precision`。
- 管理员不能重新定义这些持久契约。它们不是动态 D1 规则表；修改需要协调代码与数据迁移。
- 一个物理 BlobStore 保存持久媒体和审计归档：Cloudflare 使用 `BLOBS` R2 bucket，VPS 使用配置的文件系统目录。审计对象是规范 NDJSON，权威元数据在 SQLite 中。持久图片为 WebP，资料音频为 Ogg/Opus；服务端拒绝 MIME 不符的内容、SVG 和 GIF。
- 公开可见不代表可以修改。即使界面隐藏或禁用操作，服务端授权仍是最终依据。
- 演示数据只是开发内容，不能作为真实用户、采用率、性能或客户声明的证据。

## 产品原则

1. **所有设备使用同一任务模型。** 手机与桌面可以不同方式排版，但不能有意删减能力。
2. **公会气质配合熟悉控件。** 层级、媒体、数据和审慎交互建立身份，标准控件保持标准行为。
3. **只在需要时呈现复杂度。** 成员先看到当前信息和常用操作；管理深度受权限控制且可发现。
4. **操作应可追溯。** 敏感修改需要服务端授权和审计上下文，并明确显示破坏性操作。
5. **有价值的身份表达应保留。** 以肖像为主的成员卡、减少动效和成员控制的音频都是产品能力，而非装饰。

## 无障碍与包容性

键盘操作、可见焦点、语义标签、可读对比度、减少动效、触控目标、缩放、较长译文和内容重排都是基础要求。音频始终由用户控制，且绝不是传达信息的唯一方式。
