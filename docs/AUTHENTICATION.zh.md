# 认证与账号安全

[文档首页](../README.md) · [English version](./AUTHENTICATION.md)

本文说明 `v1.0.0` 已发布的认证行为。运维配置以 [SETUP.zh.md](./SETUP.zh.md) 为准，漏洞处理以 [SECURITY.zh.md](./SECURITY.zh.md) 为准。

## 账号模型

- 内部用户 ID 是角色、资料、内容、会话、审计记录和外部身份的持久归属键。
- 私密登录名只用于本地认证与凭据管理；成员界面使用单独的显示名。
- 注册必须持有有效邀请码，OAuth 不能绕过邀请创建成员。
- 即使配置外部登录供应商，本地凭据仍然可用。
- 站点配置拥有登录、注册、恢复、验证和状态页显示的站名及公会 Logo。已上传站点媒体的优先级高于部署默认值。

## 已支持流程

### 邀请注册

访客先验证邀请码，再提交唯一登录名、显示名和新密码。一个事务同时消费邀请并创建用户、凭据、资料和审计记录；名称冲突或邀请不可用时不消费任何内容。

### 本地登录与会话

登录使用私密登录名和密码。未知、不可用和密码错误的账号都只返回通用凭据错误。“保持登录”选项决定文档约定的会话期限。会话 token 随机生成，只以摘要形式保存，并通过 HTTP-only Cookie 发送。

浏览器通过 Web Locks 协调登录、注册、强制完成密码和退出。生产环境必须使用 HTTPS，本地开发可使用 localhost。会话修订号可阻止跨标签页的旧响应恢复先前身份。

### 修改密码与登录名

已登录成员提供当前密码后，可以修改私密登录名或密码。安全信息修改成功后，服务会递增认证修订号，并按契约使旧会话失效。

所有新密码使用同一政策：

- 8–128 个字符；
- 至少一个 Unicode 大写字母；
- 至少一个 Unicode 小写字母；
- 至少一个非空格特殊字符。

数字可选，不存在常见密码集合。门户显示的本地化规则与共享 schema、服务端实际执行的规则一致。

### 管理员凭据重置

有权限的管理员必须先确认自己的当前密码。重置会生成随机临时登录名和密码，15 分钟后过期，只能使用一次，并强制目标成员设置永久密码；同时轮换目标认证修订号、撤销已有会话和 OAuth 连接、使待处理连接 challenge 失效，并原子写入审计事件。

最后一位 owner 的恢复属于 [SETUP.zh.md](./SETUP.zh.md) 记录的运维维护流程，不依赖保存的恢复代码、邮箱或 OAuth。

### 可选 OAuth

当站点配置开关和完整部署凭据同时启用供应商时，可使用 Google、Discord 和 KOOK adapter。一个内部账号可在确认当前密码后连接多个供应商。连接绝不按邮箱自动合并账号；解除连接需要当前本地密码，并使旧认证状态失效。

微信只在共享供应商模型中预留，目前不可用。在实现经过官方规则验证前，服务端会拒绝启用微信。

### 可选已验证邮箱

配置邮件供应商后，成员可在确认当前密码后添加、验证、更换或移除联系邮箱。服务端只保存有期限、单次验证 token 的摘要。验证 token 留在 URL fragment 与短期 session storage 中，不进入普通查询日志或浏览器历史。

邮箱只是联系信息，不是登录名、邀请替代品、自动账号合并键或强制恢复渠道。

## 密码哈希与登录防护

密码使用自描述格式 `pbkdf2-sha256$iterations$salt$hash`，配合 16 字节随机 salt 和 256 位派生 key。配置默认值及最低值均为 **10,000 次迭代**，以适配 Cloudflare Worker CPU 预算。操作者只能在实测目标运行时后显式提高，上限为 10,000,000。

即使账号不存在或已存 hash 不可用，登录也会消耗一次固定配置的派生预算。较低成本的有效 hash 会在成功登录后升级。高于当前配置预算的 hash 不会被认证，因此降低已经提高过的配置前必须先迁移较强 hash。

按来源和按来源/登录名组合的限流在账号查询与 PBKDF2 前执行。产品刻意不提供持久账号冷却或管理员解锁页面。

## 请求与会话安全

- 修改请求必须具有允许的 `Origin` 和 `X-Requested-With: XMLHttpRequest`。
- 认证、邀请、OAuth 和邮箱流程各自使用专门限流。
- OAuth 使用有期限且单次的 state、供应商支持时使用 PKCE，并通过绑定浏览器的 HTTP-only 事务 Cookie 验证流程；识别身份后丢弃供应商 token。
- 受保护的身份修改和对应审计事件在同一数据库事务中提交。
- 服务端授权是最终依据；路由和组件守卫只负责界面呈现。
- 登录名、密码材料、会话 token、OAuth token 和验证 token 不能进入公开 API、URL、分析或日志。

## 配置边界

非秘密供应商开关位于站点配置。OAuth client secret 和邮件凭据只保存在 Wrangler secret 或受文件权限保护的 VPS 环境文件中。不完整的凭据对无法通过配置校验；公开能力接口只说明可用状态，不泄露凭据。

Cloudflare 与 VPS 组合相同的认证服务和契约。运行时 adapter 只提供供应商出站请求、Cookie 和存储端口，不得实现不同账号政策。

## 必要验证

认证改动必须覆盖受影响的共享 schema、服务事务、路由、两种运行时组合和门户流程。聚焦负向检查应覆盖通用失败、限流顺序、重放、冲突、会话失效、审计原子性和秘密脱敏。发布候选版本前执行 [CONTRIBUTING.zh.md](./CONTRIBUTING.zh.md) 规定的发布检查。
