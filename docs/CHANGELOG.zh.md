## [1.0.0] - 2026-09-05

### 修复

- 图库图片上传会将每张图片登记到当前系统测试运行，统一清理可移除本次测试的图库条目和媒体，不影响普通内容。批量审计标识及其校验覆盖完整上传上限；冻结的 core schema 保持不变。

### 新增

- 完整双语公会运维能力：成员、资料、活动和周期模板、公告、公会战、百科、图库、仓储、工具、通知及受权限保护的管理后台。
- 一套运行时无关应用，可部署到 Cloudflare Workers（D1/R2/Durable Objects）或单进程 Node.js VPS（SQLite/文件系统/WebSocket）。
- 可选 Google、Discord、KOOK 账号连接、可选已验证联系邮箱、邀请注册、管理员临时凭据恢复及成员账号安全控制。
- 三组由路由拥有的工作区全景，以及公共、访问和状态页各自的响应式明暗素材。
- 跟随系统和手动明暗主题、持久“减少动效”偏好、中英文切换及响应式任务一致性。

### 变更

- 认证表单使用固定标签、本地化校验、适配主题的自动填充和紧凑密码规则；资料页密码区同步清晰排版。访问与维护状态卡统一响应式间距，`/401` 提供明确登录入口；独立维护响应根据 `Accept-Language` 选择中文或英文。
- 登录、注册、恢复、验证和状态界面使用配置的公会身份；已上传站点 Logo 媒体优先于部署默认值。
- 门户启动时并行加载翻译、公开站点配置和当前会话；原始启动错误改为本地化重试状态。
- 成员与管理目录使用有界服务端分页、筛选和稳定排序；选择器可直接解析已选 ID，无需加载完整目录。
- 公告和百科使用更清楚的内容层级与共享管理操作；图库保留原始构图，并将标题放在图片外。
- 总览优先呈现当前公会活动，个人报名数据只向已登录成员显示。
- 工作页共享居中的阅读、标准和宽幅内容限制，并使用一致区块间距和响应式重排。
- 当前文档只保留持续维护的产品、设计、安全、部署、迁移、贡献、素材和发布参考，且全部提供中英文。README 包含中英文、明暗自适应的 Archify 图和实时仓库徽章。过期审查与开发期设计记录不再作为当前指南，私人草稿不纳入公开历史。

### 安全

- 新密码要求 8–128 个字符、一个大写字母、一个小写字母及一个非空格特殊字符；不存在常见密码集合。
- PBKDF2-SHA256 保留可配置的 10,000 次默认及最低迭代，以适配 Cloudflare Worker CPU 预算；凭据失败使用固定预算，较低成本 hash 在登录后升级。
- 按来源和来源/登录名组合的限流在账号查询或 PBKDF2 前执行。凭据错误保持通用；不存在持久账号冷却或管理员解锁路径。
- 修改请求要求允许的 Origin 和 `X-Requested-With`；受保护身份与业务修改在数据库事务内写入审计记录。
- 媒体校验、不透明 ID、数据库拥有的生命周期、有界垃圾回收及权限控制流式传输在 R2 和 VPS 文件系统上行为一致。
- 会话切换拒绝浏览器旧响应、跨标签页协调凭据修改，并在相关账号或角色变化后刷新授权。

### 数据库与运维

- CI 明确 Node/pnpm、编译器、lint、测试及浏览器版本，使用 frozen 安装并提供双语复现步骤。发布检查仅构建一次门户，保留两端类型检查，且不接受 lint 警告。移除已被替代的 ESLint 配置及重复或仅绑定样式的断言，保留行为、无障碍、安全和运行时一致性覆盖。
- 出库 E2E 在选择领取人前先搜索，避免前序测试新增成员后，目标成员落到目录第二页而使测试失效。
- 全新安装只使用一个冻结的 `0000_core.sql`，其中包含完整 1.0.0 schema 与权威种子数据，manifest 同样仅有一个对应条目。
- 既有数据库通过备份和维护期保护的应用账本切换升级；运行时不会重放或改写业务数据及 Wrangler 迁移历史。
- Node SQLite 与本地 workerd D1 使用相同迁移字节，并通过 schema/索引/触发器一致性检查。
- `release:check` 在本地检查边界、配置、secret、类型、lint、单元测试和两种运行时构建。CI 将完整 Chromium E2E 分到三个隔离运行器并行执行；所有任务都不会部署或修改生产资源。完整 Worker 访问日志保留在失败诊断附件中，不再刷满控制台。
- 浏览器 E2E 通过 Miniflare/workerd 直接运行编译后的 Cloudflare Worker，移除 Wrangler 开发代理的连接故障来源，同时保留两组隔离环境、全部断言及清理验证。意外的运行时自动恢复也会使该轮测试失败。
- VPS 生产构建保留必要 WebSocket 运行时依赖，并通过编译产物启动和 heartbeat 覆盖检查。
